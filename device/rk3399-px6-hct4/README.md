# Device tree: PX6 / RK3399 head unit (HCT4)

This is the device configuration for the Rockchip PX6 (RK3399) Android head unit.
It is kept here and copied into the synced LineageOS tree by `scripts/deploy_device.sh`.

## Where it lands in the build tree

    device/rockchip/rk3399/      <- PRODUCT_DEVICE must be `rk3399` (see below)
    vendor/hct4/                 <- prebuilt vendor blobs, generated by scripts/prebuilt_vendor.sh

`PRODUCT_DEVICE := rk3399` is deliberate: the build system resolves `BoardConfig.mk` from
`device/$(PRODUCT_DEVICE)/`, and keeping the device name `rk3399` also keeps
`ro.product.device=rk3399` - which is what the vendor's own `update.zip` asserts
(`getprop("ro.product.device") == "rk3399"`), so the Daisaita rollback package still installs
against our ROM.

## What is here

| file | role |
|---|---|
| `AndroidProducts.mk` | declares the lunch targets for the tree scanner |
| `lineage_rk3399.mk` | product config (name, device, inherited bases) |
| `device.mk` | HU feature/permission/property config + vendor prebuilt import |
| `BoardConfig.mk` | arch, boot image layout, dynamic partitions (super unchanged at 3,263,168,512 B - **D11**/**D19**, the 8 GiB variant of D8 is recorded in `docs/decisions.md` and rejected), SELinux |
| `fstab.rk30board` | eMMC layout with dynamic partitions and F2FS userdata (named after ro.hardware) |
| `configs/` | HU-specific rc / xml fragments copied into the images |
| *(no `sepolicy/` dir yet)* | permissive boot comes from `WITH_PERMISSIVE_SELINUX := true` in `BoardConfig.mk` (**D5**); a real device sepolicy is a post-bring-up task, and Lineage review requires enforcing (`docs/upstream.md`) |

## Vendor blobs

The vendor image is **not** built from source. It is the Daisaita Android 11 vendor tree
(gralloc/allocator+mapper 4.0 midgard = dmabuf, audio 6.0, keymaster@4.0 via optee,
health 2.1, drm 1.3, `rockchip.hardware.rockit.hw`, `rockchip.hardware.outputmanager`,
`android.hardware.mtc.mfi`) extracted from `diatsia fw/update.zip`. See `docs/decisions.md` D9.

The blob tree is ~250 MB and is **not committed** - it is regenerated from the zip:

    scripts/prebuilt_vendor.sh "../diatsia fw/update.zip" <lineage-tree>
