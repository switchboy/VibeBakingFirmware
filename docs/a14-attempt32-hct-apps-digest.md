## 2. Root-cause categories (what to port next)
1. **Missing native lib — 2 crashes**: `libcvbs_jni.so` (loaded by `com.microntek.cvbs.JniUtil`, used by `com.microntek.gl.GLFrameSurface`). Not in `/system/lib64` nor app `lib/arm64` (avin/dvd ship no lib dir). Blocks every GL/cvbs surface app (avin, dvd, and by extension frontview/backview/media/tv/carcd). Port `/system/lib64/libcvbs_jni.so` + its cvbs/audio deps.
2. **getService() == null → NPE — 1 crash**: CAN bus. `com.microntek.carcd.CanBase` is null because `android.microntek.canbus` (HCTCanBus) is set aside; no `canbus`/`HCTCanBus` string in the log. `controlinfo`'s `Canbus01CarInfo` is the same CAN client. Port HCTCanBus + register its binder service.
3. **Settings-provider writes rejected — 2 crashes + silent BT**: `android.permission.WRITE_SETTINGS` (`controlinfo`) and `IllegalArgumentException: You cannot keep your settings in the secure settings` (`radio`, `Settings$System.putInt`). Fix = privapp-permissions/appop `WRITE_SETTINGS` grant + move `Settings.System/Secure` writes to app-scoped prefs or to CarService storage.
4. **Runtime permission — 306 crashes**: `ACCESS_COARSE_LOCATION`/`ACCESS_FINE_LOCATION` for uid 10104 (travel). Needs a granted location permission (or drop `requestLocationUpdates` in `RecService.initLocationListener`).
5. **Missing binder/intent targets**: `com.android.settings.GPS_APPCHOOSE` unresolved (HCT GPS/settings chooser activity not installed); `BluetoothAdapter: Bluetooth service is null` x5 (Android BT service absent); Java `mfiservice` not registered — the HIDL side **is** present (`avc: { add } for interface=android.hardware.mtc.mfi::IMfi sid=... pid=491`), kernel `--mtc MFI ACD 908`, so the Java MFI/`mtcbt` service must be re-registered.
6. **System permissions denied**: `ACCESS_SURFACE_FLINGER`, `INTERNAL_SYSTEM_WINDOW`, `ROTATE_SURFACE_FLINGER` (navisettings, wheelstudy) → overlays/rotation features dead.
7. **Removed Android-10 APIs: none observed.** 0 `NoSuchMethodError`, 0 `NoClassDefFoundError`, 0 `ClassNotFoundException`, 0 hidden-API lines — the boot-classpath shim (`android.microntek.*`) resolves; `android.preference.*` still exists on API 34.
8. **Vendor/HAL noise (not app bugs)**: `android.hardware.drm@1.0::IDrmFactory/default` not registered (3663 lines, 2293 `init` errors) → DRM users (media/dvd/music) will fail once cvbs is fixed; camera HAL reports 0 cameras; `Gralloc3: mapper 3.x is not supported`, `GRALLOC-MOD: validateBufferSize failed, layer count is invaild` x217; 1042 `DeprecatedTargetSdkVersionDialog` lines (targetSdk=26 on all HCT apps).
