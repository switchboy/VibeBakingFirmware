# Third-party assets

* Gauge and weather icons (`app/res/drawable/ic_gauge_*.xml`, `ic_wx_*.xml`): [Material Design Icons](https://pictogrammers.com/library/mdi/)
  by Pictogrammers, `@mdi/svg` 7.4.47, Apache License 2.0. Converted from SVG to Android vector drawables (path data unchanged).
* Weather data: [Open-Meteo](https://open-meteo.com/) (CC BY 4.0), no API key.
* Rain radar: [RainViewer](https://www.rainviewer.com/) public API; base map © OpenStreetMap contributors (ODbL).
